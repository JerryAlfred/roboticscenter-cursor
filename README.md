# Silicon Valley Robotics Center

A modern, responsive website showcasing the Silicon Valley Robotics Center and featuring a comprehensive robot ranking system.

## 🚀 Features

- **Modern Design**: Clean, professional interface with smooth animations
- **Robot Rankings**: Comprehensive ranking system for humanoid, quadruped, and service robots
- **Interactive Details**: Detailed robot profiles with specifications, features, and comparisons
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Search & Filter**: Advanced filtering and search capabilities
- **Contact Integration**: Built-in contact forms and Calendly integration

## 🤖 Robot Categories

- **Humanoid Robots**: Atlas, Optimus, ASIMO, Pepper
- **Quadruped Robots**: Spot, ANYmal, Laikago, A1
- **Service Robots**: Roomba and more

## 🛠️ Technology Stack

- **HTML5**: Semantic markup and modern structure
- **CSS3**: Advanced styling with Flexbox and Grid
- **JavaScript**: Interactive features and dynamic content
- **Font Awesome**: Professional icons
- **Google Fonts**: Inter font family

- **AWS S3** + CloudFront
- **Any web server**

## 🔧 Local Development

1. Clone the repository
2. Open `index.html` in your web browser
3. Or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   ```
